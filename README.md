Programmable turns versioned Uniswap v4 contracts into launch flows that do not require a creator to write Solidity.
The contracts, tests, fixed parameters, security assumptions and Ethereum deployment evidence behind each available
model are public.

| Explore | Public record |
| --- | --- |
| Launch models and lifecycle status | [Model library](https://github.com/0xprogrammable/programmable/blob/main/MODELS.md) |
| Verified Ethereum addresses and runtime hashes | [Deployment record](https://github.com/0xprogrammable/programmable/blob/main/deployments/ethereum.json) |
| Trust assumptions and known limitations | [Security](https://github.com/0xprogrammable/programmable/blob/main/SECURITY.md) |
| External hook submissions | [Hook Builder Program](https://github.com/0xprogrammable/programmable/blob/main/BUILDER_PROGRAM.md) |

## Build a model

Independent builders can submit complete open-source Uniswap v4 launch models as pull requests. Submission does not
guarantee review, acceptance, deployment, volume or revenue.

[Read the requirements](https://github.com/0xprogrammable/programmable/blob/main/BUILDER_PROGRAM.md) ·
[Open the repository](https://github.com/0xprogrammable/programmable)
