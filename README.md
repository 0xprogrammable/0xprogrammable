## One interface. Independent models.

The interface handles setup. The selected model defines token creation, its Uniswap v4 pool, fee accounting, liquidity
custody and hook behavior as one versioned release.

New models extend the library. They do not rewrite an existing deployment.

## Bring a new mechanic.

Bring an idea or an existing public Uniswap v4 project. Keep the complete project in your own public repository. The
Builder helps a compatible coding agent check one exact revision and prepare the small public application pull request,
so source, evidence and review stay traceable.

```bash
gh skill install \
  0xprogrammable/programmable \
  programmable-v4-hook-builder
```

[Read the Builder guide](https://github.com/0xprogrammable/programmable/blob/main/docs/builder/AGENT_SKILL.md) ·
[See the submission requirements](https://github.com/0xprogrammable/programmable/blob/main/BUILDER_PROGRAM.md)

silently change one that has already been deployed.
